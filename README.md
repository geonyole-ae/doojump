# 두들 점프

브라우저에서 바로 하는 두들 점프 스타일 게임입니다. HTML5 Canvas와 순수 JavaScript로 만들었고 외부 라이브러리는 쓰지 않습니다.

**플레이:** https://geonyole-ae.github.io/doojump/

## 조작법

| | PC | 폰 |
|---|---|---|
| 이동 | `←` `→` 또는 `A` `D` | 기울이기 (안 되면 화면 아래쪽 왼쪽/오른쪽 누르기) |
| 쏘기 | `Space` 또는 `↑` | 탭 (기울기를 안 쓰면 화면 위쪽 탭) |
| 일시정지 | `P` 또는 `Esc` | 오른쪽 위 버튼 |
| 소리 | `M` | 오른쪽 위 버튼 |

## 게임 요소

- 발판: 초록(일반), 파랑(움직임), 갈색(부서짐), 흰색(1회용)
- 아이템: 스프링, 프로펠러 모자, 제트팩
- 방해 요소: 몬스터(밟거나 쏘기), 블랙홀(피하기)

## 로컬에서 실행

`index.html`을 브라우저로 열면 됩니다.
